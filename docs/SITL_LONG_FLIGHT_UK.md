# Довгий SITL-політ і перегляд точного запису

## Рішення

Один заздалегідь зафіксований 45-секундний політ при TWR = 5 завершився
без контакту, відмов керування та таймаутів маневру. Усі критерії цього
прогону виконані. Завдання довгого прогону та автономного переглядача
закрите; додаткового підбору ваг, PID, геометрії чи порогів не виконували.

Це перевірка **Candidate A разом із координатором і польотним контуром**.
Вона не є новим порівнянням нейронних кандидатів і не змінює висновки
[MVP_SELECTION_UK.md](MVP_SELECTION_UK.md). Мережа, активний пакет та
режим за замовчуванням в інтерактивному demo залишені незмінними.

Артефакти: `output/sitl_bringup_v1/long_flight_v1/`.

## Що саме працювало

- Candidate A: `output/tau_continuation_v1/adaptive_tau/numpy`,
  конфігурація `configs/demo_candidate_a.json`.
- SHA-256 metadata:
  `ebb9517a1bb7acc7eef99e1c933ece5f7387012eee30fc3a2e15c2d114937896`.
- Незмінний фазовий координатор зі згладженим Yaw та синхронізацією
  виходу при AUTO; `levy_explore=False`.
- Реальний процес модифікованого Betaflight SITL і PyBullet у lockstep:
  фізичний крок 250 мкс, керування 20 мс.
- Flow/attitude 50 Гц, дальномір 30 Гц, ToF 15 Гц; штатний sensor hold.
  Сенсори ідеальні, без шуму; деротація flow використовує точний стан.
- FlightSystem → SessionReceiver → перетворення еталонних PWM
  у фактичну RC-криву віртуального FC. Доставка миттєва, приймач
  перевіряється на кожному фізичному кроці.
- TWR = 5 через `max_rpm ≈ 13361,94` та раніше виміряну карту
  колективної тяги. Маса, інерція, PID, моторна затримка не підбиралися.
- Контакт: неперервна перевірка проходження сфери радіусом 0,20 м.
  Після контакту політ закінчується; удар та відскок не моделюються.

Перед цим [ізольовані однакові Yaw-імпульси](SITL_YAW_TWR_UK.md)
пройшли обидва напрями при TWR = 5: фізичне згасання 0,31325 с,
максимальна похибка висоти 0,740 см. Номінальні контрольні траси
побітово відтворили попередній експеримент. Це обґрунтувало перехід
до довгого прогону без нового налаштування регуляторів.

## Сцена і зафіксовані критерії

Кімната: X/Y від −6 до +6 м, Z від 0 до 3 м. Старт `(0, 0, 1)`, yaw = 0.

| Об’єкт | Геометрія, м |
|---|---|
| Бокс 1 | X [2,2; 2,8], Y [−0,65; 0,25], Z [0; 2,5] |
| Бокс 2 | X [−3,2; −2,4], Y [1,6; 2,8], Z [0; 2,5] |
| Циліндр 1 | центр (2,0; 3,3), радіус 0,45, висота 2,5 |
| Циліндр 2 | центр (−1,8; −2,8), радіус 0,55, висота 2,5 |

Тривалість 45 с, запит STOP від 40 с. Критерії до запуску:
повний горизонт без контакту/помилки; зазор ≥10 см; похибка висоти ≤10 см;
швидкість XY <0,03 м/с протягом останньої секунди; безперервне AUTO
після штатного допуску; правильний годинник та прийняті команди.
Протокол і SHA-256 джерел записані **до** польоту у `protocol.json`.

Останні дві частки мають різний зміст: фазовий шар може володіти каналом,
навіть якщо його команда випадково збігається з мережею; повний XY-шар
включає також штатний STOP та базові втручання. Їх не можна складати
або називати часткою «самостійності мозку».

Годинник: усі фізичні кадри послідовні, +250 мкс на крок, по два
оновлення моторного виходу FC. Усі прийняті команди збігаються з
виданими; receiver trip не було. Зафіксовані джерела протягом польоту
не змінювалися (`sources_unchanged=True`).

### Що відбулося на маршруті

| Час, с | Подія |

| 7,28 → 7,72 → 8,26 → 8,76 | BRAKE → TURN → RECOVER → CRUISE біля першого бокса |
| 23,63975 | Найменший зазор при проходженні біля циліндра 1; фаза CRUISE |

Дві перешкоди в лівій частині кімнати залишилися поза маршрутом.
Отже, наявність чотирьох об’єктів **не означає чотири перевірені обходи**.
Це один успішний маршрут із двома фазовими маневрами, проходженням
біля циліндра та фінальною зупинкою. Покриття всієї кімнати не було метою.

## Як подивитися

Відкрити `output/sitl_bringup_v1/long_flight_v1/replay.html` звичайним
браузером. Docker, сервер та інтернет для перегляду не потрібні.

- «Відтворити» / пауза, шкала часу, швидкість 0,25×–2×.
- Обертання камери мишею, наближення колесом, вигляд зверху.
- Схематична модель дрона в масштабі сцени; пунктир — радіус оболонки.
- Фаза, джерело команди, висота, швидкість, зазор, матриця ToF та її вік.
- Команди мережі, координатора та приймача по вибраному каналу.

Це **офлайн-відтворення**, без повторного запуску фізики чи мережі.
Видимі позиції — записані стани на контрольних тактах плюс кінцевий
стан (2251 кадр). Інтерполяції або згладжування траєкторії немає.
Метрики у звіті обчислюються на повних 180000 фізичних кроках.

У `trace.npz` ToF збережений до різночастотного утримання, тому
переглядач бере кадр за **capture timestamp** з `command_trace.json`.
Це показує саме отримане контролером вимірювання; свіжа істина
фізики не видається за сенсорні дані. Відсутній capture-кадр або
неузгоджені часові мітки спричиняють помилку експорту.

Графіки PWM показують еталонні одиниці **до** RC-перетворення FC.
Вони не є безпосередніми командами моторів. Прийнята команда до
входу AUTO відсутня, а не вигадана рівною ручному fallback.

`replay.png` — статичний огляд; `replay.audit.json` — хеші джерел і
переглядача; `browser_audit.json` — перевірка завантаження, перемотування,
play/pause та кінцевого STOP. Браузерних JavaScript-помилок не виявлено.

## Зміни коду й перевірка

1. `evaluate/sitl_neural.py`: явні `horizon_s` / `stop_at_s`; попередні
   значення за замовчуванням 20/17 с збережено. Час має збігатися із
   сіткою 20 мс, для оцінки STOP потрібна щонайменше повна секунда.
   Рівняння контролера і фізики не змінені.
2. `evaluate/sitl_long_flight.py`: одна фіксована сцена, перевірка
   калібрування, протокол до запуску, метрики повної фізичної траси.
3. `evaluate/render_sitl_replay.py` + `evaluate/sitl_replay.html`:
   автономний переглядач і PNG із наявних файлів.
4. `tests/test_sitl_long_flight.py`, `tests/test_sitl_replay.py`:
   тести спершу відтворили відсутність реалізації; після реалізації
   перевіряють часовий контракт, метрики, held ToF, кінцеву позицію,
   відсутні accepted-команди та безпечне вбудовування JSON у HTML.

Разом із тестами сенсорного адаптера, інтеграції та TWR: **39 passed**.
Перший запуск інтеграційних тестів не зміг створити тимчасову папку
середовища; повтор із явною тимчасовою папкою в репозиторії пройшов.
Це не вимагало змін контролера чи тестових очікувань.

Повторне створення переглядача без повтору польоту:

```powershell
.\venv\Scripts\python.exe -m evaluate.render_sitl_replay `
  --run output/sitl_bringup_v1/long_flight_v1/flight `
  --out output/sitl_bringup_v1/long_flight_v1/replay.html
```

Повтор фізичного досліду потребує працюючого Docker та нового каталогу
результатів (наявний не перезаписується):

```powershell
$repoPath = (Get-Location).Path
$resultsPath = (Resolve-Path 'output/sitl_bringup_v1').Path
docker run --rm --network none --cpus 4 --memory 2g --workdir /work `
  --mount "type=bind,source=$repoPath,target=/work,readonly" `
  --mount "type=bind,source=$resultsPath,target=/results" `
  chong-fly-sitl:neural-v1 python -u -m evaluate.sitl_long_flight `
  --out /results/long_flight_repeat --source /results/lockstep_v1 `
  --calibration-source /results/twr_sensitivity_v1_run
```

## Межа завершення

Маємо придатний до огляду довгий запис роботи незмінної A в повному
SITL-контурі при TWR = 5. Немає підстав через цей результат знову
відкривати навчання або перебір параметрів координатора.

Наступна змістовна перевірка — обмежена серія із зафіксованими шумами,
затримками та похибками сенсорів, після перегляду цього запису.
Виміри реальних сенсорів звузять діапазони, але сам апарат у зборі
для програмної перевірки не потрібний. До цієї серії в поточному
кроці не переходимо: довгий прогін та візуалізацію вже завершено.
