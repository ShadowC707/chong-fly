# Де губиться завершення маневру: градієнти й прихований стан

Дата: 05.11.2026. Продовження `BALANCED_MANEUVER_TRAINING_UK.md`. Це діагностика без оптимізатора, зміни ваг, нових польотів або заміни робочої моделі.

## Що виміряно

Для початкового та кінцевого plastic-чекпойнтів `balanced_maneuver_v1` обчислено градієнти тих самих частин навчальної цілі:

- `recorded` — повна channel-v4 ціль на всіх 104 навчальних епізодах; градієнти пакетів підсумовані з нормуванням на весь набір;
- `history` — Pitch MSE всіх кадрів останнього навчального етапу, 24 історії зі спільним закінченням 4с;
- `cruise_x10` — вільний рух із фактичною вагою10;
- окремо складові історій: clear, unsettled, settled;
- додаткова **діагностична, не навчальна** ціль `narrow_repair`: квадрат дефіциту відхилення Yaw до80PWM на конкретному слабкому стимулі (лівий стовпець,0.70м).

Використано ті самі дозволені навчальні параметри plastic-гілки (A заморожена). Стани параметрів і нетензорні метадані контракту порівняно до/після. Жодного кроку оптимізатора не було. CUDA цього сеансу недоступна; розрахунок виконано на CPU. Перший CPU-запуск зупинився до вимірювань через обробку нетензорних полів state_dict; це виправлено окремим регресійним тестом. Валідна серія — `output/maneuver_gradient_audit_v2`; `v1` позначена як перервана.

## Локальний конфлікт підтвердився

Косинус градієнтів: +1 — однаковий напрямок, −1 — протилежний, 0 — ортогональні. Значення наведені для об'єднаних навчальних параметрів у їхній поточній параметризації.

| Пара втрат | Початкова модель | Навчений кандидат |
|---|---:|---:|
| Повні епізоди / історії | +0.966 | **−0.846** |
| Історії / крейсерський рух×10 | +0.918 | −0.228 |
| Завершене / незавершене гальмування | +0.981 | **−0.9993** |

У кінцевій моделі градієнти двох протилежних цілей гальмування майже взаємно компенсуються. Норми окремих градієнтів — 0.825 і0.945, норма сумарного градієнта історій — лише0.0284. Конфлікт не обмежений декодером: для W косинус settled/unsettled=−0.9996, для tau_raw=−0.9961.

Важливо: це **не доводить суперечності міток**. Для різних минулих входів різні правильні команди допустимі. Наявний кандидат не утримує потрібної відмінності станів, тому спільні параметри отримують майже протилежні запити на виправлення.

Локальна похідна loss історій уздовж від'ємного повного градієнта становить +0.000692, тоді як для повних епізодів −0.001573. Тобто нескінченно малий звичайний градієнтний крок у цій точці зменшував би ціль епізодів, але збільшував ціль історій. **Це не відтворення реального наступного кроку Adam:** тут немає його накопичених моментів, масштабування за параметрами, обрізання градієнта чи проєкції W/tau. Не можна з цього зробити причинний висновок про всі попередні300 оновлень або гарантувати ефект зміни ваг loss.

## Відмінність губиться вже в ядрі

Окремо записано всі306 прихованих станів на перевірочних історіях без clamping. Для прикладу flow=0.16, загроза зліва, останні8с входів однакові:

| Час від початку епізоду | L2 різниці всіх станів unsettled/settled | Різниця Pitch, PWM | Потрібна різниця Pitch |
|---|---:|---:|---:|
| 1.0с — початок однакових входів | 0.78676 | −83.34 | −321.04 |
| 1.5с | 0.13788 | −12.82 | −257.04 |
| 2.0с | 0.04735 | −4.22 | −257.04 |
| 4.0с | 0.00342 | +0.039 | −257.04 |
| 9.0с | 0.000451 | +0.021 | −257.04 |

Зменшується різниця не тільки на вузлах, доступних декодеру Pitch, а й у всьому прихованому стані. Наприкінці чотирьох перевірочних flow в обох напрямках максимальна покомпонентна відмінність станів не перевищує0.000417. Отже, версія «потрібна пам'ять зберігається добре, достатньо посилити readout» цими трасами не підтримується. Малий ненульовий залишок є, але вихідна різниця на порядки менша за потрібну й інколи має інший знак.

Це спостереження на скінченних історіях, не доказ глобальної стійкості чи неможливості реалізувати пам'ять цією rate-моделлю. Раніше інші навчені параметри вже давали розрізнення історій; задача полягає в його збереженні разом з іншою поведінкою.

## Що відомо про слабкий вузький поворот

Для дефіциту вузького Yaw напрямок виправлення майже ортогональний поточному повному градієнту: косинус +0.0306. Зокрема для декодера Pitch-history та вузького Yaw косинус0, що узгоджується з різними вихідними каналами. Через спільне ядро внески можуть перетинатися.

Це **не підтверджує**, що одна й та сама градієнтна суперечність безпосередньо спричинила ослаблення вузького повороту. Поточна ціль слабко спрямована на виправлення саме цього дефекту, але причина його виникнення ще не ізольована. Не можна автоматично лікувати обидва дефекти одним множником loss.

## Практичне рішення

Не запускати ще один довгий прогін із випадково підібраними вагами трьох цілей. Наступний обґрунтований контроль має перевіряти **утримання відмінності внутрішніх станів після події завершення гальмування**, а не лише середню помилку PWM. Можливий вузький напрям — допоміжний навчальний сигнал для розрізнення цих історій, без передачі стану вчителя у входи inference та без додавання зовнішнього координатора. Його постановку й вплив на Yaw треба окремо перевірити; ця діагностика не доводить, що конкретний новий loss розв'яже проблему.

Вузький рефлекс залишається окремою умовою збереження попередньої поведінки. Апаратні контракти й робочий пакет не змінені. Нових експериментальних ваг у цій серії немає.


Допоміжні скрипти побудови графіка і трас збережені поруч із результатами. Хеші вихідних чекпойнтів/даних та активного пакета перевірені; жодної зміни параметрів чи оптимізаційного кроку не виконано.
