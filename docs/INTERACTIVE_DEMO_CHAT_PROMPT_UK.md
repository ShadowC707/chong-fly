# Стартовий промпт для іншого чату

Працюємо в репозиторії Chong-Fly. Потрібно реалізувати локальний інтерактивний демонстратор для захисту проєкту: проста 3D-сцена з квадрокоптером, синхронні графіки й сенсори, replay прогонів і жива симуляція з клавіатурою як ручним пультом.

Спочатку прочитай **`docs/INTERACTIVE_DEMO_HANDOFF_UK.md`**. Це погоджене технічне завдання: мета, порядок реалізації, джерела коду, ідентичність моделі, режими MANUAL/SHADOW/AUTO, часові контракти та критерії прийняття. Потім перевір фактичний стан репозиторію й API потрібних модулів.

Я дозволяю реалізацію цього демонстратора поетапно. Почни з огляду і короткого пояснення обраної структури, потім переходь до роботи. Не зупиняйся лише на плані. Якщо інформації для певного кроку бракує, назви конкретну залежність і продовжуй незалежну частину.

Перевикористовуй наявні standalone-фізику, pinned NumPy FlightSystem і приймач команд. Ваги, контролери, admission, sensor age budgets та lease/deadline не підлаштовуй під UI. Не замінюй відсутній checkpoint випадковою мережею або вчителем. Реального підключення до дрона, прошивання, навчання й переписування Git-історії тут не потрібно.

Ручний режим першої версії — горизонтальне керування з підтриманням висоти. Реалізуй чіткі повноваження, ручне перехоплення, SHADOW preview та AUTO лише через чинний admission. Втрата фокуса, пауза, reset і подвійне оновлення stateful controllers мають бути явно опрацьовані. Replay і жива симуляція повинні бути помітно розрізнені.

Працюй із TDD для нового керування, станів і часу; візуальну частину перевір фактичним запуском. Регулярно пояснюй, що змінив, навіщо і чим це перевірив. Важливі нові проблеми математичної моделі або інтеграційних контрактів фіксуй окремо для основного чату, де ми продовжуємо їхню валідацію.

У результаті потрібні одна точка запуску, інструкція для демонстрації викладачу, невеликий набір перевірених записів, screenshots і чесний список обмежень. На цьому етапі важливі зрозумілість, відтворюваність і працездатність без інтернету, а не фотореалізм.
