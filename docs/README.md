## Карта папок

- `core/`, `simulation/policy.py` — математична модель і сенсорні/вихідні проєкції.
- `generator/` — джерела конектоми, редукція, вчитель, дані навчання.
- `optimizer/` — навчання, відбір, функціональні досліди.
- `simulation/` — фізика, сенсорні моделі, сцени, спільні XY/Altitude контролери.
- `edge/` — NumPy inference, контракти інтеграції, приймач, експорт і offline release.
- `artifacts/` — спільні завантажувачі й публікація артефактів.
- `evaluate/` — спостереження й перевірки цілих контурів.
- `scripts/` — спеціалізовані досліди та їхні датовані пояснення.
- `configs/`, `tests/` — явні конфігурації й регресійні перевірки.
- `data/` — обрані відстежувані артефакти та ігноровані локальні результати.
- `archive/` — локальні резервні копії, не частина Git checkout.

XY/Altitude контролери поки залишаються в `simulation/`: вони потрібні і runtime,
і фізичним дослідам. Перенесення лише заради назви папки не є вимогою MVP.

їхні старі шляхи, числа й відкриті задачі не заміняють поточний README.
Зокрема, згадки видалених файлів у старому інвентарі — історичні записи.
