# Вибір MVP: стара мережа, кандидат A та фазовий координатор

Дата: 2026-11-08. Серія: `output/mvp_selection_v1`.
Статус: **усі 12 прогонів завершено; навчання й підбору параметрів не було**.

## Рішення

1. **Кандидат A має виміряне покращення самої мережі.** Із тим самим базовим
   XY-координатором він завершив 4/4 прогони без зіткнень, проти 1/4 старої
   моделі, і прибрав виміряний відкат: 1,6945 → 0 м. Фазовий координатор
   для цього результату не використовувався.
2. **Стару модель не обираємо для продовження роботи.** A залишається
   зафіксованою нейронною основою; повторне навчання за результатами цієї
   серії не запускається.
3. **Для повного затвердження A + SmoothPhasedCoordinator критерій ще не
   виконаний:** 3/4 проходів замість 4/4. У `9d5431c1_mirror` зазор до
   бічної колони становив 6,86 см при наперед установленій межі 10 см.
   Активний пакет і стандартний режим симулятора не замінено.
4. Конкретний блокер — **бічний запас під час початкового обходу до
   активації фазового маневру**, а не неправильний знак першого повороту
   в цих чотирьох замкнених прогонах. Корекція порогу чи нове навчання
   автоматично з цього не випливають і в цю серію не додавалися.

Цей крок завершений. Результат не заміняється формулюванням «потрібні ще
тести»: є відхилена стара модель, обрана нейронна основа A і один конкретний
незакритий критерій повної гібридної системи. Окреме обмеження дзеркальної
реакції мережі також збережене нижче, без твердження про повну симетрію.

## Протокол, записаний до польотів

- Дві початкові кімнати `9d5431c1`, `b0a9f212` з користувацьких записів
  `flight simulations/changed contract`; кожна — в оригінальній і
  віддзеркаленій щодо Y геометрії. Віддзеркалені також старт і yaw.
- Три режими: `original_xy`, `candidate_xy`, `candidate_smooth`.
- Горизонт 45 с, без запланованого STOP. Корпус — сфера радіуса 0,2 м,
  колізії `sphere-sweep-v1`.
- Фізика — **історичний standalone DemoRunner**, де спостерігався дефект;
  не Betaflight/SITL. Фізика 250 Гц, керування 50 Гц, чинний різночастотний
  сенсорний контракт і чинний шум із фіксованим seed.
- Це нові парні прогони на збереженій геометрії, не побітове відтворення
  старого запису. Після встановлення явної геометрії береться початковий
  сенсорний відлік. Дзеркальні польоти не зобов'язані мати побітово
  віддзеркалену реалізацію шуму; дзеркальний сенсорний replay точний.
- Спільність resolved RunConfig перевірена: відрізняються тільки пакет і
  його checksum. Обидві базові системи використовують однакові спільні
  XY/Altitude/Bridge контракти, підтверджені pinned-завантажувачем.
- SHA-256 пакетів, початкових записів, конфігурацій і Python-коду зафіксовано
  в `protocol.json`; після серії незмінність підтверджено.

Правильний початковий бік визначений **без запуску моделей**: прямолінійне
горизонтальне наближення від старту кроками 1 см до першого ToF <1 м;
порівняння середніх дальностей половин, обрізаних зверху 2 м, із різницею
понад 5 см. Це мітка видимого початкового просвіту, не глобального маршруту.

| Старт | Очікуваний знак reference Yaw |
|---|---:|
| 9d5431c1 native | +, праворуч |
| 9d5431c1 mirror | −, ліворуч |
| b0a9f212 native | −, ліворуч |
| b0a9f212 mirror | +, праворуч |

Виражений поворот: |Yaw−1500| ≥50 PWM одного знака на трьох послідовних
керуючих тактах AUTO. Для допуску потрібні правильний перший прийнятий
поворот, 45 с без контакту/fault, безперервний AUTO після входу і запас
≥10 см **на кожному** старті. Сумарний відкат має бути меншим за стару модель.
Відкат вимірюється інтегралом від'ємної швидкості вздовж осі корпусу при
швидкості <−0,03 м/с. «0 м» нижче означає нуль за цим критерієм, не заборону
будь-якого малого зворотного зміщення через шум.

## Порівняння

| Показник | Стара + XY | A + XY | A + плавний фазовий |
|---|---:|---:|---:|
| Правильний перший прийнятий поворот | 4/4 | 4/4 | 4/4 |
| Прогони без зіткнень, повні 45 с | 1/4 | 4/4 | 4/4 |
| Проходження всіх критеріїв напрямку й безпеки | 0/4 | 1/4 | 3/4 |
| Сумарний відкат, м | 1,6945 | 0 | 0 |
| Найменший зазор, см | 0 | 2,49 | 6,86 |

Старі прогони зіткнулися на 12,472 / 43,804 / 26,448 с. Відкат не
екстраполюється до 45 с: порівнюється фактично пройдена траєкторія;
старі невдалі польоти мали меншу тривалість спостереження.

| Старт | Зазор, см: стара / A / A+фазовий | Час <10 см, с: стара / A / A+фазовий |
|---|---|---|
| 9d5431c1 native | 0 / 2,49 / **30,17** | 1,824 / 2,652 / **0** |
| 9d5431c1 mirror | 0 / 6,86 / **6,86** | 4,768 / 4,916 / **8,056** |
| b0a9f212 native | 0 / 5,92 / **15,87** | 4,212 / 4,948 / **0** |
| b0a9f212 mirror | 6,86 / 15,61 / **15,61** | 2,852 / 0 / **0** |

У дзеркальному 9d5431c1 фазовий режим **збільшив** час нижче 10 см на
3,14 с відносно A+XY. Цю регресію не приховано відсутністю зіткнення.

Фазовий координатор володів хоча б одним каналом на 10,6–40,6% тактів
AUTO, залежно від старту. Частка тактів із реальною зміною R/P/Y
відносно мережі — 17,0–45,0%; це інша метрика, що включає базовий XY.
Координатор забезпечує істотну частину виконання маневру, а не лише
косметично згладжує вже готову траєкторію.

## Що покращилося саме в мережі

На кожному фактичному сенсорному потоці обидві мережі працювали як
незалежні спостерігачі з однаковими dt й reset. Їхні виходи не втручалися
в рух, крім явно обраного драйвера. Вихід незалежного спостерігача-драйвера
на кожному такті точно збігся з виконуваною policy. Це також перевірило
узгодженість старого pinned runtime і спільного NumPy replay.

На чотирьох потоках, породжених **старою моделлю**, обидві мережі обрали
правильний початковий бік; A дала виражену реакцію раніше:

| Старт | Від першого ToF <1 м до вираженого Yaw: стара / A, с |
|---|---:|
| 9d5431c1 native | 0,58 / **0,20** |
| 9d5431c1 mirror | 0,64 / **0,24** |
| b0a9f212 native | 0,78 / **0,30** |
| b0a9f212 mirror | 0,74 / **0,30** |

Тут немає підміни різними траєкторіями: у кожному рядку входи ідентичні.
Порівнюються повні версії моделі, включно зі зміною сенсорної підтримки
0,8→1,0 м, інтерфейсу та tau. Ця серія не ізолює внесок кожної зміни.

![Обидві мережі на однакових історіях старої моделі](../output/mvp_selection_v1/same_input.png)

Висновок «стара модель завжди обирає ліворуч» **не підтвердився**:
в усіх чотирьох фізичних стартах перший виражений поворот був правильним
навіть у старої моделі. Невдачі виникали пізніше. Значна частина початкової
проблеми стосувалася відкату, часу реакції й виконання обходу.

## Залишкова нейронна асиметрія — не приховуємо

Додатково кожну із 12 сенсорних історій віддзеркалено: flow Y змінює знак,
ToF міняє порядок стовпців; reset збережені. Входи кільцевої пам'яті
перевірено як відключені, нової пам'яті немає.

У 24 комбінаціях «історія / її дзеркало» початковій мітці відповів знак
першого вираженого повороту у 16 випадках старої моделі та у 22 випадках A.
Два старі replay взагалі не дали вираженого повороту. Це **не 24 незалежні
сцени** і не статистична оцінка ймовірності успіху. Дуже пізній перший
поворот може вже стосуватися іншої загрози; тому цей рахунок не підміняє
часові криві і не використовується для зміни допуску заднім числом.

Два незбіги A — віддзеркалення потоків `b0a9f212_native_candidate_xy`
та `b0a9f212_native_candidate_smooth`. Зокрема у першому потоці правильна
початкова позитивна реакція була слабкою (максимум близько +14 PWM у
перші 1,5 с після ToF<1 м), а перший виражений поворот став негативним
через 2,24 с. **Повної дзеркальної узгодженості самої мережі немає.**
Реальний замкнений дзеркальний політ при цьому мав правильний перший
поворот: він породжує іншу історію входів, ніж пасивний replay.

## Локалізація єдиного блокера гібридного режиму

У `9d5431c1_mirror_candidate_smooth`:

- мінімум **0,0686146 м** о **10,956 с**, позиція приблизно
  `(1,17324; 0,20491; 0,99882)` м;
- найближчий об'єкт — циліндр №0, центр `(1,24691; −0,35875)` м,
  радіус 0,29984 м; це зазор оболонки, радіус дрона вже віднятий;
- швидкість близько 0,208 м/с; координатор ще у **CRUISE**;
- перший BRAKE почався лише о **11,54 с**, приблизно на 0,584 с пізніше;
- фронтальний ToF біля цього моменту близько 0,94 м, вище порогу
  активації фазового режиму 0,85 м. Це інша геометрична величина,
  ніж мінімальний зазор корпусу до бічної поверхні.

`posthoc_audit.json` містить останній **попередній** керуючий такт перед
мінімумом, геометрію найближчого об'єкта, PWM усіх стадій і рішення
координатора. Параметри після цього аналізу не змінювалися.

Конкретне завдання перед затвердженням гібридного варіанта — зберегти
бічний запас під час цього початкового обходу. Не встановлено, що просте
підвищення порогу BRAKE чи посилення Yaw це виправить без регресії;
такого виправлення ця серія не випробовувала.

## Файли, перевірки, відтворення

- `evaluate/mvp_selection.py` — протокол, 12 польотів, пасивні спостерігачі,
  дзеркальний replay, метрики і первинне рішення.
- `evaluate/report_mvp_selection.py` — читання готових трас, додаткові
  графіки та локалізація мінімального зазору; не змінює первинний допуск.
- `tests/test_mvp_selection.py` — віддзеркалення, часовий критерій повороту,
  відсутність втручання спостерігачів і узгоджений reset.
- `output/mvp_selection_v1/protocol.json`, `report.json`, `decision.json`,
  `posthoc_audit.json`; у кожного прогону manifest, фізична траса, п'ять
  стадій команд, рішення координатора та обидві версії сенсорного replay.

**21 цільовий тест пройдено**, включно з переходами плавного Yaw,
профілями demo та pinned runtime. Перший запуск перевірок мав помилку
створення тимчасового каталогу; повтор із `--basetemp` у проєкті пройшов.
Повний suite не запускався. Усі зафіксовані вхідні файли й пакети незмінні.

```powershell
.\venv\Scripts\python.exe -m evaluate.mvp_selection --out output/mvp_selection_repeat --workers 3
.\venv\Scripts\python.exe -m evaluate.report_mvp_selection output/mvp_selection_repeat
.\venv\Scripts\python.exe -m pytest tests/test_mvp_selection.py tests/test_phased_yaw_smoothing.py tests/test_demo_controller_profiles.py tests/test_pinned_system.py -q -p no:cacheprovider --basetemp .test-tmp-mvp-selection-repeat
```

Каталог нової серії має не існувати. Автоматичного навчання, експорту,
зміни активної конфігурації або переходу до TWR у цьому скрипті немає.
